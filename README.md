## Estructura de cada apunte

- **Objetivos de la sesión** (los del docente).
- **Desarrollo**: todo el contenido técnico de la presentación, organizado en secciones, con tablas, código en bloques `c` y diagramas en **Mermaid**, que GitHub renderiza en la vista previa.
- **Participación y ejercicios**: los ejercicios de clase con las respuestas dadas en el material y una *pauta* breve para los abiertos.
- **Resumen**, **Ticket de salida / Control** (con respuestas de guía) y **Glosario** de términos nuevos.
